1. Run "AmongUsDotNetInstaller.exe" (this app is made by Pietro, we can all trust him, run it anyway regardless of what your anti-virus says)
2. Follow its instructions but don't click Launch at the end yet
3. After the progress bar finishes, remember the folder where you've installed the mono version of the game for step 4
4. Take all files in this folder apart from "INSTRUCTIONS.txt" and "AmongUsDotNetInstaller.exe" and put them into that folder
5. Have Steam running in the background
6. Run "Among Us.exe" from this folder, or click Launch in "AmongUsDotNetInstaller.exe" if you still have it open

For Epic Games, you need to have the newly created folder at the exact same location with the exact same name as the original AmongUs folder, and launch from the Epic Games launcher (delete the old folder or rename it)

Feel free to delete "INSTRUCTIONS.txt" and "AmongUsDotNetInstaller.exe" after you've successfully completed all steps and got EHR to load properly.
